====================
Pagewide CSS classes
====================

:Extension key:
    pageclasses

:Package name:
    svent/pageclasses

:Version:
    |release|

:Language:
    en

:Author:
    Sven Tappert

:License:

    `Creative Commons BY 4.0 <https://creativecommons.org/licenses/by/4.0/>`__
    license.

:Rendered:
    |today|

----

Adds one or more CSS classes to the body tag of the rendered pages. Classes
can be set per page and for all subpages of a page, they are inherited down
the page tree, and classes for the frontend and backend layout of a page are
added automatically.
